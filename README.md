
#Pocket Player
Offline music player that runs in your browser. Add your own MP3, FLAC, M4A, or WAV files — nothing is uploaded to a server.

Features: local library, tags & cover art, playlists, lyrics, lock-screen controls, themes (Sleek / iPod / Mac · light & dark).

#Use
Open the page (or add to Home Screen).

Tap + Add and pick songs.

Play, build playlists, edit info from ⋯.

#Host
Single static HTML file. Host on GitHub Pages or any static host. Music stays in each visitor’s browser only.
